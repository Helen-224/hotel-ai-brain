# Hotel AI Brain

面向单家酒店的智能运营协调平台。当前交付第一轮：产品介绍网站，含五层架构交互、角色价值切换、核心场景分步预览。两份原始需求资料保持原样。

## 本地运行

需要 Node.js 22+。

```sh
npm install
npm run dev
```

访问终端显示的本地地址。生产检查：`npm run build`；预览构建：`npm run preview`。

## 当前边界与演示

按首页叙事浏览产品理念 → 点击五层架构各层 → 切换四类角色 → 进入场景并逐步查看流程。所有数字为虚构场景数据，切换仅解释流程，不调用模型、不创建任务、不连接外部系统。没有虚假的平台登录或已执行状态。

## 开发路线

1. 当前：产品介绍与信息架构，响应式导航、架构探索、角色价值、流程预览。
2. 下一轮：统一平台布局和角色工作台，建立页面路由与关联数据模型。
3. 随后：模拟数据适配器、服务端数据读取、风险分析、结构化协调计划与中央 Agent 工具。
4. 最后：数据库持久化、权限、审批、员工执行、日志与最新状态验证。

P1/P2 扩展功能不纳入当前阶段。没有声称节省成本、增加利润或已连接真实酒店系统。

## 目录

- src/main.tsx：产品总览、角色与场景交互
- src/components/Architecture.tsx：可交互五层架构
- src/data/content.ts：架构与场景内容
- src/style.css：统一视觉、响应式与无障碍焦点

## 配置与默认决策

当前采用 Vite + React + TypeScript，适合第一阶段介绍网站；数据库和服务端模块按后续业务阶段引入。当前不需要数据库或 OpenAI Key，也不读取环境变量。`.env.example` 仅记录后续服务端配置，不代表相关能力已实现。后续数据库迁移、真实模型接入与模拟模式切换将在对应阶段提供可运行配置；密钥不得使用 VITE_ 前缀暴露到客户端。

默认中文、深绿企业风格、桌面优先兼容移动端；重要操作保留人工决策。平台入口当前指向场景预览并明确说明建设阶段，避免空白工作台。
